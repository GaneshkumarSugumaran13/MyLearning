Here are the exact changes required in your script to support a column-aware dynamic ambiguity margin.

---

### 1. In `ReconciliationConfig` Dataclass

**Find:**

```python
    # Best candidate must beat second-best candidate by this
    # margin. Otherwise record is considered ambiguous.
    ambiguity_margin: float = 0.05

```

**Replace with:**

```python
    # Best candidate must beat second-best candidate by this
    # margin. Otherwise record is considered ambiguous.
    ambiguity_margin: float = 0.05

    # Target maximum column differences allowed between best and second-best
    # candidate before declaring ambiguity (e.g., 1.0 means ambiguity triggers
    # only when scores differ by less than 1 full column's weight).
    ambiguity_max_column_diff: float = 1.0

```

---

### 2. In `find_best_candidate()` Function

**Find:**

```python
    if (
        len(scores) > 1
        and (best_score - second_best_score) < config.ambiguity_margin
        and (best_raw - second_best_raw) < config.ambiguity_margin
    ):
        return (None, best_score, second_best_score, "AMBIGUOUS")

```

**Replace with:**

```python
    # Dynamic margin: scale threshold so a gap of 'ambiguity_max_column_diff'
    # columns (or fewer) triggers ambiguity. capped by absolute ambiguity_margin.
    total_cols = len(legacy_row)
    if total_cols > 0:
        effective_margin = min(
            config.ambiguity_margin,
            config.ambiguity_max_column_diff / total_cols,
        )
    else:
        effective_margin = config.ambiguity_margin

    if (
        len(scores) > 1
        and (best_score - second_best_score) < effective_margin
        and (best_raw - second_best_raw) < effective_margin
    ):
        return (None, best_score, second_best_score, "AMBIGUOUS")

```

---

### How this works for your 71-column file

* With `ambiguity_max_column_diff = 1.0`, the threshold dynamically adjusts to $\frac{1.0}{71} \approx 0.014$ (1.41%).
* Candidates that differ by 2 or more columns from the top candidate will no longer trigger `AMBIGUOUS`.
* If you want to tighten or loosen this behavior on CLI execution, pass `--ambiguity-max-col-diff 0.5` (half a column difference) or `--ambiguity-max-col-diff 2.0`.
